📐 find_pattern_angle

반도체 웨이퍼 다이 그리드처럼 반복되는 줄무늬 패턴이 있는 영상 한 장만 있으면, 영상 처리로 그 패턴이 이미지 축 대비 몇 도 기울어져 있는지 역산할 수 있습니다. 스테이지·카메라 정렬 확인이나 웨이퍼 회전 오차 측정에 쓰는 기법입니다.

지금 사용해보기

이미지 한 장을 올리면 브라우저에서 바로 패턴 각도를 계산합니다. 서버 전송 없음.

소스 코드 (GitHub)

Python 구현체(estimate_pattern_angle.py)와 검증용 스크립트, 샘플 이미지를 모두 확인할 수 있습니다.

어떻게 동작하나요

1. 전처리그레이스케일 변환 + Hanning 윈도우, 필요 시 중앙 원형 마스크를 적용합니다.
2. 각도 탐색0~180°를 성기게 훑으며 각 각도로 회전 후 열 합의 고주파 에너지를 계산합니다.
3. 정밀 재탐색coarse 최댓값 근방만 촘촘한 스텝 + 3차보간으로 다시 훑습니다.
4. 서브디그리 보간3점 포물선 보간으로 최종 각도를 서브픽셀 단위로 산출합니다.

예제로 확인한 정확도

두 샘플 이미지는 같은 웨이퍼 다이를 촬영한 뒤 하나를 약 30° 돌린 것입니다. 웹 도구에서 두 예제 버튼으로 직접 확인해볼 수 있습니다.
